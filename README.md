# RentIt

A hyperlocal peer-to-peer rental marketplace. People rent idle items (tools, gear, equipment) to neighbours. Platform earns commission on each transaction.

**Status:** Ideation / validation — no product built yet.

## The idea

Owners list idle household/hobby/trade items. Renters nearby discover and rent per day. Platform earns 15–20% commission per completed transaction.

See full brief → [`smtg/founder/board/brief.md`](smtg/founder/board/brief.md)  
See board assessment → [`startup-brain/wiki/decisions/founder-board-assessment.md`](startup-brain/wiki/decisions/founder-board-assessment.md)

**Founder board verdict: 3× FUND IF | Avg 3.7/10**

Three things to resolve before building:
1. Damage & trust policy designed end-to-end
2. Cold-start plan — specific first neighbourhood + 50 listings path
3. One item category + one geography chosen and defended
